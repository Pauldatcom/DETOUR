Lancer le simulateur dans un autre terminal avec `python3 server/app.py --demo`, puis ouvrir `http://127.0.0.1:8765/dashboard`.

Pour les TP d'agentique, il faut Node.js 20+, une clé OpenRouter, un modèle gratuit compatible avec les appels d'outils et la clé d'équipe transmise par le formateur. Gardez les clés hors du dépôt et de la page web.
